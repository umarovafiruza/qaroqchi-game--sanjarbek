# Xazina Ovchisi - Sirli Orol Sarguzashtlari 🏝️🏴‍☠️

2D sarguzashtli arcade o'yini. Canvas va toza JavaScript (Vanilla JS) asosida yaratilgan. O'yin to'liq o'zbek tilida tayyorlangan bo'lib, desktop va mobil qurilmalarga to'liq moslashtirilgan (responsive).

---

## 🎮 O'yin Maqsadi
* Xarita bo'ylab qaroqchilar va xavfli tikanli tuzoqlardan qoching.
* Barcha oltin tangalar va xazina sandiqlarini to'plang.
* Yashiringan **kalitni** toping va qulfdan chiqarilgan **chiqish eshigi** orqali keyingi bosqichga o'ting.
* Jami 10 ta qiziqarli va tobora murakkablashib boruvchi bosqich mavjud!

---

## 🕹️ Boshqaruv Tugmalari

### 🎮 Yangi 360° Analog Jostik (Controller):
* Ekranning chap pastki qismidagi interaktiv analog **Jostik** orqali qahramonni erkin 360 darajada harakatlantiring (Sensorli ekran yoki Sichqoncha orqali).
* Ekranning yuqori o'ng qismidagi `🎮` tugmasi orqali jostikni xohlagan paytda ko'rsatish yoki yashirish mumkin.

### 💻 Kompyuterda (Desktop):
* **Harakatlanish:** Jostik yoki `W`, `A`, `S`, `D` / `Strelkalar (▲ ◀ ▼ ▶)`
* **Phantom Dash (Tezkor oldinga otilish):** `Space` (Bo'sh joy) yoki ekrandagi `💨 DASH` tugmasi
* **Sehrli olovli to'p:** `F` yoki ekrandagi `⚡ SEHR` tugmasi
* **Muz Blizzard sehri:** `Q` yoki ekrandagi `❄️ MUZ` tugmasi
* **Pauza:** `P` yoki `Esc`
* **To'liq ekran:** `F11` yoki ekrandagi `⛶` tugmasi

### 📱 Smartfon va Planshetlarda (Mobile):
* Chap qo'l: Sensorli 360° Virtual Analog Jostik
* O'ng qo'l: Ergonomik harakat tugmalari (`💨 DASH`, `❄️ MUZ`, `⚡ SEHR`)
* Yuqori o'ng burchak: Gamburger menyu (Pauza, Jostik, Ovoz, To'liq ekran)

## ✨ Maxsus Imkoniyatlar va Sehrlar
* 🌀 **Astral Portallar:** Bir portaldan kirib ikkinchisidan chiqish.
* 🛡️ **Sehrli Qalqon:** Dushman zarbalaridan himoya.
* 🧲 **Kosmik Magnit:** Atrofdagi tangalarni o'ziga tortadi.
* 👻 **Ko'rinmaslik Mantiyasi:** Dushmanlar sizni ko'ra olmaydi.
* ⏳ **Vaqtni Sekinlashtirish:** O'yin tezligini sekinlashtiradi.
* ❓ **Qiziqarli Savol-Javob (Viktorina):** Bilimingizni sinash va qo'shimcha ballar olish imkoniyati.

## 🚀 Ishga Tushirish

### 1-usul: To'g'ridan-to'g'ri brauzerda
1. Papkadagi `Oyinni_Boshlash.bat` faylini bosing yoki
2. `index.html` faylini istalgan zamonaviy brauzerda oching.

### 2-usul: Lokal server (Localhost)
Terminalda quyidagi buyruqni bering:
```bash
python -m http.server 8000
```
Brauzerda: `http://localhost:8000` manziliga kiring.
